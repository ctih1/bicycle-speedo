# Bicycle-Speedo
A digital speedometer for bikes.

## Hardware
I built this project around an ESP32, some hall-effect sensors, and an ILI9341. I'm not gonna get to the setup or wiring as this is not supposed to be a tutorial.
I haven't made the 3D casing for the screen and ESP32 yet, so this currently isn't installed.
